# SAGT--Simple_Arduino_Game_Tools
This is a set of libraries written or rewritten specifically for creating simple games on the Arduino microcontroller.

## Dependencies

This project uses the following third-party library:

- **[LiquidCrystal_PCF8574](https://github.com/mathertel/LiquidCrystal_PCF8574)** by **Matthias Hertel** (Copyright © 2005-2016).
  - **License:** BSD 3-Clause
  - **Purpose:** Used for controlling I2C LCD displays.
